Server Storage and RAID

Storage performance can have a significant impact on server performance.

Enterprise servers may support SAS, SATA and SSD storage technologies. Businesses should consider capacity, speed, reliability and workload requirements when selecting drives.

RAID 1

Provides disk mirroring and redundancy.

RAID 5 / RAID 6

Provides redundancy while maintaining useful storage capacity.

RAID 10

Combines mirroring and striping for performance and redundancy.

It is important to remember that RAID is not a replacement for backups. Critical business data should have an independent backup strategy.

Firewalls and Network Security

Security is another important part of an organization's IT infrastructure.

Firewalls help control traffic between networks and can provide functions such as VPN connectivity, application control, access policies and threat protection.

Businesses may use security products from manufacturers such as Fortinet, Cisco, SonicWall and Palo Alto Networks.

Security should be more than a firewall

Organizations should also consider software updates, secure passwords, multi-factor authentication, access controls, endpoint protection and regular backups.
